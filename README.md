# Velora – Marketing agency website

A static website (HTML, CSS and JavaScript only). No build step is needed.

## Files
- `index.html` – the page structure (Home, Work, Packages and Team pages)
- `style.css` – black and gold theme and layout
- `script.js` – floating marketing icons, mouse sparkles, page transitions, team and Instagram post features
- `logo-wordmark.jpg`, `logo-full.jpg`, `velora-logo-original.jpg` – your logo

Keep all files in the same folder.

## Publish on GitHub Pages
1. Create a new repository on github.com, for example `velora-website`.
2. Click **Add file > Upload files**, drag in every file from this folder (not the folder itself), then click **Commit changes**.
3. Open **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/velora-website/`.

## Notes
- Team photos and Instagram posts added through the forms are saved in the visitor's own browser only. To show them to everyone, add the images to this folder and put them in the code.
- Fonts (Cormorant Garamond and Manrope) load from Google Fonts, so an internet connection is needed.
